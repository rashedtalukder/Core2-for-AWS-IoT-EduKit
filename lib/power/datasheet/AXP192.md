# Communication Interface

### Bus Type

Two Wire Serial Interface (TWSI / I²C compatible)

### Device Address

```
7-bit address: 0x68
```

### Clock Speed

```
400 kHz – 1.2 MHz
```

### Electrical Levels

```
Logic low input  <= 0.3 V
Logic high input >= 2.0 V
Supply voltage for interface: 3.3 V
```

Typical wiring:

```
SDA -> pull-up 2.2k to 3.3V
SCK -> pull-up 2.2k to 3.3V
```

---

# Power Architecture

AXP192 manages power sources:

```
BAT     — Lithium battery
VBUS    — USB input
ACIN    — External adapter
```

Output system rail:

```
IPSOUT
```

Internal logic rail:

```
VINT (2.5 V internal logic power)
```

IPS automatically selects the best power source.

Priority order:

```
ACIN > VBUS > BAT
```

Behavior:

1. Battery only → system powered by battery
2. External power present → external power supplies load
3. Battery automatically supplements load if external supply insufficient
4. ACIN preferred over VBUS when both present


Active when:

```

```

```

```

---

When battery reaches:

```

```

---

### Charge Termination

Occurs when:

```

```

Restart when:

```
VBAT < VTRGT − 0.1V
```

## REG00H — Power status bits

The datasheet explicitly defines these status bits: `REG00H[7]` ACIN present, `[6]` ACIN usable, `[5]` VBUS present, `[4]` VBUS usable, `[3]` VBUS above VHOLD, `[1]` ACIN/VBUS short on PCB, `[0]` system powered on by ACIN/VBUS; it also states battery current direction is indicated by `REG00H[2]`.

```c
#define AXP192_STATUS_ACIN_PRESENT         (1u << 7)
#define AXP192_STATUS_ACIN_AVAILABLE       (1u << 6)
#define AXP192_STATUS_VBUS_PRESENT         (1u << 5)
#define AXP192_STATUS_VBUS_AVAILABLE       (1u << 4)
#define AXP192_STATUS_VBUS_ABOVE_VHOLD     (1u << 3)
#define AXP192_STATUS_BAT_DIR              (1u << 2) /* direction indicator; datasheet says REG00H[2] indicates charge/discharge */
#define AXP192_STATUS_ACIN_VBUS_SHORT      (1u << 1)
#define AXP192_STATUS_BOOT_BY_ACIN_VBUS    (1u << 0)

/* Conservative enum for REG00H[2]:
   the datasheet says REG00H[2] indicates whether battery current is charge or discharge,
   but the polarity is not stated in the excerpt. */
typedef enum {
    AXP192_BAT_DIR_DISCHARGE_OR_CHARGE_0 = 0,
    AXP192_BAT_DIR_DISCHARGE_OR_CHARGE_1 = 1
} axp192_bat_dir_t;
```

## REG30H — VBUS to IPSOUT path control

The datasheet explicitly states: `REG30H[7]` participates in VBUS input selection, `REG30H[6]` enables VBUS pass-through mode, `REG30H[5:3]` configures `VHOLD`, `REG30H[1]` enables current limiting mode, and `REG30H[0]` selects `500mA/100mA`. It also says default `VHOLD` is `4.4V`.

```c
#define AXP192_VBUS_USE_ENABLE             (1u << 7)  /* REG30H[7] */
#define AXP192_VBUS_PASS_THROUGH           (1u << 6)  /* REG30H[6] */
#define AXP192_VBUS_VHOLD_MASK             (0x7u << 3)/* REG30H[5:3] */
#define AXP192_VBUS_CUR_LIMIT_ENABLE       (1u << 1)  /* REG30H[1] */
#define AXP192_VBUS_CUR_LIMIT_SEL          (1u << 0)  /* REG30H[0] */

#define AXP192_VBUS_VHOLD_SHIFT            3

typedef enum {
    AXP192_VBUS_CUR_LIMIT_100MA = 0,
    AXP192_VBUS_CUR_LIMIT_500MA = 1
} axp192_vbus_cur_limit_t;
```

The exact `VHOLD[2:0] -> voltage` lookup is not present in the excerpt I can cite, so I won’t invent that table. What is grounded is that the field is `REG30H[5:3]` and default is `4.4V`. 

## REG31H — VOFF / warning / wake behavior

The datasheet explicitly says `REG31H[2:0]` participates in `VOFF`/warning defaults and `REG31H[3]` controls the sleep/wakeup restore behavior.

