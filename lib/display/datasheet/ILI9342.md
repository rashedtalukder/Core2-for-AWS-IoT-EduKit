# ILI9342C LCD Controller Reference

## Device Overview

**ILI9342C** is a single-chip TFT LCD driver supporting:

* **Resolution:** 320 × 240 pixels (RGB subpixel addressing)
* **Color depth:** up to **262,144 colors**
* **Integrated GRAM:** 172,800 bytes
* **Source outputs:** 960
* **Gate outputs:** 240
* **Interfaces supported**

  * MCU parallel: 8-bit, 9-bit, 16-bit, 18-bit
  * Serial: 3-wire SPI, 4-wire SPI
  * RGB interface: 6-bit, 16-bit, 18-bit

The device contains:

* Internal display RAM (GRAM)
* Timing generator
* Oscillator
* Charge pump power system
* VCOM generator
* Backlight PWM controller
* Gamma correction circuitry
* Dynamic backlight control

The display driver supports:

* Full color mode (262K colors)
* Reduced color mode (8 colors)
* Sleep mode
* Partial update regions
* Vertical scrolling
* Frame synchronization via tearing signal

# Internal Architecture

Major blocks:

* MCU interface controller
* Serial interface controller
* RGB interface controller
* Graphics RAM (GRAM)
* Address counter
* Source driver (960 outputs)
* Gate driver (240 outputs)
* Charge pump power circuits
* VCOM generator
* Gamma voltage generator
* LED PWM controller

GRAM stores full display image data for **320×240 RGB pixels**. 

---

# Display RAM (GRAM)

## Size

```
172,800 bytes
```

This stores pixel data for the entire display.

## Addressing

Pixel addressing uses:

```
Column Address
Page Address
```

* Column corresponds to **X coordinate**
* Page corresponds to **Y coordinate**

Commands configure the active window before memory writes.

# Data Transfer Behavior

Display writes operate as:

1. Command sets addressing window
2. Memory write command begins GRAM transfer
3. Pixel stream written sequentially

Data transfers can be paused and resumed.

---

# Memory Addressing Commands

## Column Address Set (2Ah)

Defines horizontal window.

Parameters:

```
start_column_high
start_column_low
end_column_high
end_column_low
```

Range:

```
0 – 319
```

---

## Page Address Set (2Bh)

Defines vertical window.

Parameters:

```
start_page_high
start_page_low
end_page_high
end_page_low
```

Range:

```
0 – 239
```

---

## Memory Write (2Ch)

Writes pixel data into GRAM.

Data format depends on selected pixel format.

Writes auto-increment GRAM address.

---

# Memory Access Control (36h)

Controls display orientation and color order.

Bit fields:

| Bit | Function                 |
| --- | ------------------------ |
| MY  | Row address order        |
| MX  | Column address order     |
| MV  | Row/column exchange      |
| ML  | Vertical refresh order   |
| RGB | RGB/BGR order            |
| MH  | Horizontal refresh order |

---

# Pixel Format Set (3Ah)

Defines pixel format for host interface.

Possible values:

| Value | Format        |
| ----- | ------------- |
| 55h   | 16-bit RGB565 |
| 66h   | 18-bit RGB666 |

---

# Vertical Scrolling

Configured using:

```
33h – Vertical Scrolling Definition
37h – Vertical Scroll Start Address
```

Parameters define:

```
Top Fixed Area (TFA)
Vertical Scrolling Area (VSA)
Bottom Fixed Area (BFA)
```

Condition:

```
TFA + VSA + BFA = 240
```

---

# Partial Display Mode

Command:

```
30h – Partial Area
```

Parameters:

```
start row
end row
```

Only selected rows are updated.

---

# Tearing Effect Output

Pin:

```
TE
```

Enabled with command:

```
35h
```

Modes:

* V-blank only
* V-blank + H-blank

Used for synchronization between MCU and display refresh.

---

# Gamma Control

Commands:

```
E0h – Positive Gamma
E1h – Negative Gamma
```

The controller supports **4 preset gamma curves**:

| Curve | Function  |
| ----- | --------- |
| GC0   | y = x^2.2 |
| GC1   | y = x^1.8 |
| GC2   | y = x^2.5 |
| GC3   | y = x^1.0 |

---

# Power Control Registers

Power control commands configure:

* internal DC/DC converters
* VCOM voltage
* step-up circuits
* power modes

Commands:

```
C0h – Power Control 1
C1h – Power Control 2
C2h – Power Control 3
C3h – Power Control 4
C4h – Power Control 5
C5h – VCOM Control
```

---

# Reset Behavior

Reset pin:

```
RESX
```

Active low.

Reset clears:

* internal registers
* GRAM access pointer
* interface state

---

# Power Sequencing

Power-on sequence requires:

1. VCI stable
2. Release RESX
3. Wait internal initialization
4. Send Sleep Out command
5. Configure registers
6. Enable display

---

# GPIO

GPIO0-7 are configurable via registers:

```
C6h – read GPIO
C7h – write GPIO
```

Direction and state configurable.

---

# Backlight PWM

Pin:

```
PWM_OUT
```

Backlight control commands:

```
B8h – B9h – BAh – BBh – BCh – BDh – BEh
```

Features:

* PWM brightness
* dynamic backlight control
* CABC integration

---

# Nonvolatile Memory

Commands:

```
D0h – NV Memory Write
D1h – NV Protection Key
D2h – NV Status
```

Stores configuration parameters.

---

# Supported Display Modes

| Mode       | Colors   |
| ---------- | -------- |
| Full color | 262K     |
| Idle mode  | 8 colors |

Idle mode reduces power consumption.

---

# Tearing Synchronization

The **TE output pin** provides frame synchronization so the MCU can write GRAM during safe periods to avoid visible tearing.
